# Technical Documentation Page 📄

A fully responsive, single-page technical documentation template built with HTML5 and CSS3. This specific page serves as a reference guide for JavaScript (content sourced from MDN), but the layout can be easily adapted for any official documentation, API guide, or manual.

## ✨ Features

- **Fixed Sidebar Navigation:** On desktop screens, the navigation bar stays fixed on the left side of the screen, allowing users to scroll through the content without losing the menu.
- **Internal Page Routing:** Clicking any link in the navbar smoothly jumps to the corresponding section of the document using HTML anchor tags (`href="#id"`).
- **Responsive Design:** A mobile-first approach using CSS Media Queries (`@media (max-width: 815px)`). On smaller screens, the fixed sidebar moves to the top of the page for better UX.
- **Code Snippet Formatting:** Clean, readable styling for programming blocks using `<pre>` and `<code>` tags.
- **Semantic HTML5:** Structured with accessibility and SEO in mind using `<main>`, `<nav>`, `<section>`, and `<header>` tags.
